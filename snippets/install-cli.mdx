Run directly with `npx` (no install needed):

```bash
npx @mandate.md/cli login --name "my-agent"
```

Or install globally:

<Tabs>
  <Tab title="bun">
    ```bash
    bun add -g @mandate.md/cli
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm install -g @mandate.md/cli
    ```
  </Tab>
</Tabs>
